**Alter 1.1** adds a Linux version. It's a small command-line tool, one Python 3 script with no dependencies: `alter new "Chrome Work" --app google-chrome` makes a copy with its own data folder and its own entry in the app menu. It works with Chrome, Firefox, Electron apps like VS Code and Discord, Flatpak apps and most others.

Every release is now built and tested automatically on real Windows and Linux machines, including two Chrome copies running side by side. [Download it for Windows or Linux](/alter/#install).
